# Minitask 5 - Project Interaktif Go

Project ini menggabungkan fungsi dari Minitask 1 sampai 4 ke dalam satu aplikasi
berbasis menu. Setiap fitur ditempatkan pada package yang berbeda di dalam folder
`internal`.

## Daftar menu

1. Sapaan
2. Hitung luas dan keliling persegi panjang
3. Tampilkan pola kotak
4. Sisipkan angka 88 ke tengah slice
5. Tampilkan data pengguna
0. Keluar

Setelah sebuah fitur selesai dijalankan, aplikasi akan kembali menampilkan menu.

## Menjalankan program

Pastikan Go sudah terpasang, kemudian jalankan perintah berikut dari folder
project:

```bash
go run .
```

Untuk memeriksa seluruh package:

```bash
go test ./...
```
